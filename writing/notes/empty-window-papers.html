Ten papers, one weekend build

The reading list behind The Empty Window and the digital-twin-sensor repository — what each paper actually says, what I took from it, and how far it made it into code. Kept separate from the essay on purpose. Four changed the code, two changed it partially, four are read and roadmapped.

PaperWhat it saysKey context I took from itIn the build
X-SYNTHEnterprise context can be synthesised from observed digital attention rather than authored documents.The core wager of the whole project: watch attention, not content. Became the Digital Twin Signature, the attention filters and evidence weighting.In the code
Digital Twins as Funhouse MirrorsLLM-based human twins correlate weakly with the people they model and distort systematically.The most useful paper proposed no capability at all. It is why the thing is called a sensor and not a twin, and why it surfaces evidence gaps instead of speaking as anyone.In the code
Trust Calibration in Twin AgentsNames the schema, epistemic and model-artefact gaps that open when an agent represents a person.Confidence, evidence age and attribution shipped on every context pack before anything is allowed to speak for the person observed.In the code
Sweeney, k‑anonymity (2002)A record is protected when it is indistinguishable from at least k−1 others.The aggregation floor in the synthesis layer: themes below the subject floor are withheld and counted, never summarised. The one pre-LLM paper here, and the one doing the most work.In the code
A-MemAgentic memory whose notes link to each other and evolve rather than append.Context cards that get rewritten as evidence changes, instead of an append-only log. The linking half is thinner in my build than in the paper.Partly
Agent-Native Memory SystemsDecomposes memory into representation, extraction, retrieval and maintenance.Memory health as something you operate, not assume — exposed as checks. The maintenance loop is the least finished part of the sensor.Partly
Context Engineering SurveyFrames retrieval, processing, management, memory and tool reasoning as one pipeline.Changed the framing rather than any module: the product is a pipeline with a gate, not a dashboard. No single line of code traces to it; the architecture does.Framing
Memory in the Age of AI AgentsA taxonomy of the forms, functions and dynamics of agent memory.The event / sphere / graph / pack split maps onto its taxonomy. Useful as a map for what the sensor still is not.Roadmap
Agentic Context EngineeringContexts curated as evolving playbooks without collapsing into mush.The planned curation strategy for packs once there is more than one machine of evidence. Read, understood, not built.Roadmap
Context Engineering via Digital-Twin MDPOffline trajectories and reward estimation for evaluating context policies.The eventual use for the feedback labels the sensor already collects: score pack policies offline before changing them live. Furthest from the code today.Roadmap
